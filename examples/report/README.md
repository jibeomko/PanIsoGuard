# Example report — `showcase.report.pdf`

A ready-to-view example of the [`panisoguard-report`](../../python) PDF output:
**[showcase.report.pdf](showcase.report.pdf)** (8 pages, landscape).

It is rendered from a **synthetic but engine-consistent** fixture (`showcase.attribution.jsonl`
+ `showcase.provenance.log`, 62 isoforms) deliberately crafted to exercise **every page and
every evidence axis** at once — so the example shows the full range of the report, which no
single real run does:

- all 7 confidence classes (HIGH_CONF_KNOWN … ARTIFACT, PAN_REF_RESCUED_FALSE_NOVEL)
- every axis on: short-read, BAM mapping, variant, pangenome, multi-caller consensus
- reference-bias rescues that are **promoted** and rescues **held by the circularity firewall**
- SQANTI3 bio priors (CAGE/polyA/NMD/motif) on the pass-through page

The fixture is a **documentation artifact**, not a real adjudication — it is generated by
`make_showcase.py`, not by the engine. (For reports from real runs, see the
[benchmark](../../benchmark) protocols; e.g. the 5-caller `multicaller` run produces a
consensus-rich report, and the `hg002` run a variant-rescue report.)

## Regenerate

```bash
python make_showcase.py showcase                 # writes showcase.attribution.jsonl + .provenance.log
pip install ../../python                          # installs panisoguard-report (needs matplotlib)
panisoguard-report --prefix showcase              # -> showcase.report.pdf
# or without installing:  python -m panisoguard.report --prefix showcase
```

See [../../python/README.md](../../python/README.md) for what each page contains.
